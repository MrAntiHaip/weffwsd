# Хроники Глубин: Дима и Ульяна — Сюжетный Мод для Minecraft Fabric 1.20.1

Этот архив содержит **полный исходный код, текстуры, рецепты и авто-сборщик GitHub Actions** для вашего сюжетного мода на **Minecraft 1.20.1 (Fabric)**.

## Что реализовано в моде:
1. **Две сюжетные роли (`/role dima` и `/role ulyana`)**:
   - **Дима (Гео-Штурмовик)**: пассивное Сопротивление в глубоких шахтах, усиленное бурение и **бонус x3** при выпадении Джекпота в Компасе Удачи.
   - **Ульяна (Хранительница Эфира)**: **+12% к шансу выигрыша** во всех барабанах Рулетки Компаса, повышенная Удача и Эфирный Резонанс.
2. **Невыбрасываемый Компас Удачи (`dima_ulyana_quest:fortune_compass`)**:
   - Заблокирован от выбрасывания клавишей `[Q]` и перетаскивания из инвентаря через `SoulboundCompassMixin`, а также сохраняется после смерти.
   - **Быстрая Рулетка ("Деп ресурсов")**: крутится без долгих задержек по **ПКМ**, а по **Shift + ПКМ** переключает 5 барабанов ставок:
     1. `64x Булыжник`
     2. `16x Железных слитков`
     3. `12x Золотых слитков`
     4. `8x Алмазов`
     5. `2x Незеритовых слитка`
   - В каждом барабане всегда есть шанс на **нубский ресурс** (`Нубская Земля «Слёзы Шахтёра»`, `Гнилая Плоть Неудачи`, `Утешительная Палка`), но с каждым уровнем прокачки кирки (от 1 до 6) шанс на крутой куш растёт с **38% до 94%**!
3. **6 уровней прокачки кирок с крутыми частицами, ломанием и баффами**:
   - **Ур. 1 — Земляная Кирка «Корневой Упор»**: частицы спор мха, бонусный дроп булыжника из земли, Сытость и Спешка I.
   - **Ур. 2 — Кремнево-Базальтовый Крушитель**: бурение туннелем **1x3**, частицы пламени и постоянная Огнестойкость.
   - **Ур. 3 — Изумрудно-Резонансная Кирка**: цепное разрушение жил (**VeinMiner**), сонар по ПКМ, Спешка II и Ночное Зрение.
   - **Ур. 4 — Алмазно-Грозовая Кирка «Импульс»**: бурение кубом **3x3**, электрические искры и **вакуумный магнит** (весь дроп телепортируется прямо в инвентарь!).
   - **Ур. 5 — Незеритово-Магмовый Колос**: бурение **3x3x2**, пламя душ, Сила II и Сопротивление II.
   - **Ур. 6 — Хроно-Звёздный Бур «Сингулярность»**: неразрушимая кирка, сфера бурения **5x5**, полёт/левитация по ПКМ и пробой сюжетного Бедрока!
4. **Сюжетные события мира (`/story_event <id>`)**:
   - `/story_event compass_gold_fever` — Золотая Лихорадка Компаса
   - `/story_event tectonic_meteor_vein` — Тектонический Разлом (Супер-Жила)
   - `/story_event gambler_archivist_deal` — Сделка Странствующего Архивариуса

## Как получить готовый `.jar` файл через GitHub (без установки Java на ПК):
В архив уже встроен файл **`.github/workflows/build.yml`**!
1. Создайте новый репозиторий на [GitHub.com](https://github.com/new).
2. Загрузите туда распакованные файлы из этого ZIP-архива.
3. Перейдите во вкладку **Actions** в вашем репозитории — GitHub автоматически соберёт готовый мод `Dima-Ulyana-Fabric-1.20.1-Mod` за ~1 минуту!

## Или сборка локально через IntelliJ IDEA / Терминал:
```bash
./gradlew build
```
Готовый файл мода появится в папке `build/libs/dima-ulyana-quest-fabric-1.20.1-1.0.0.jar`. Скопируйте его в `.minecraft/mods` вместе с **Fabric API 1.20.1**.
